DAY 08 / POST-PUBLISH CONTROL

發布之後才是真正的考驗

用 Audit Trail 與 Incident Pack，讓 AI 變更可追溯、可復原。

Release → Observe → Recover責任鏈不在發布按鈕後斷掉
一小時後健康檢查變紅誰做了什麼？現在真的恢復了嗎？
TRACE → RECOVER
版本發布出去，不代表事情結束。真正的考驗，往往是在一小時後：健康檢查變紅、使用者開始回報錯誤，但團隊還找不到完整的行動紀錄。Day 8 要把發布後的追蹤與復原，變成可以回看的證據。

01 / THE INCIDENT

證據散落各處

紅燈出現，但現場沒有共同時間線。

每個人都記得一小段；沒有人能還原全部。

01
09:12部署完成版本已出去
09:18健康檢查失敗監控亮紅燈
09:21聊天室說回滾沒有正式事件
09:29工單補描述時間已經落後
?版本與核准人不明誰負責？
問題 沒有共同 change id，就很難回答「這次事故到底屬於哪個變更？」
post-publish / incident timeline02
想像一個很常見的情境：變更已經部署，監控卻在幾分鐘後亮起紅燈。有人在聊天室說「先回滾」，有人在工單補描述，還有人只記得自己做過檢查。事後回頭看，沒有人能快速回答：哪個版本、誰核准、何時開始、為什麼回滾。

02 / THE CHAIN

同一個 CHANGE ID

把發布後流程串成一條責任鏈。

重要動作都留下事件，按順序回讀。

02
e1核准release approved
e2部署deployed
e3健康檢查failed
e4事故opened
e5回滾started
e6恢復resolved
change_idorders-export-20260811
post-publish / ordered evidence03
解法不是多寫一份報告，而是讓每一個重要動作都留下事件。從發布核准、部署、健康檢查，到事故開啟、回滾與恢復，全部使用同一個 change id 串起來。這條時間線，就是 Audit Trail，也就是可追溯的行動紀錄。

03 / AUDIT TRAIL

APPEND-ONLY JSONL

只追加，不覆寫。

每一筆事件都是可回讀的證據。

post-publish / immutable evidence04
在範例裡，Audit Trail 採用只追加、不覆寫的 JSONL。每筆事件都有 event id、時間、事件類型、變更 id 和證據。重複的 event id 會被拒絕，不同變更 id 混在同一條時間線也會被拒絕。這些限制，讓紀錄不會在事故後被悄悄改成另一個故事。

04 / INCIDENT PACK

HANDOFF WITHOUT GUESSING

事故交接，不靠「我記得」。

把現場整理成下一個人能直接判斷的包。

04
01

發生什麼

版本、時間、健康檢查與影響範圍。

02

誰做了什麼

核准、部署、調查、回滾與責任人。

03

現在好了嗎

resolved 事件、恢復證據與後續行動。

時間線＋證據＋目前狀態＝Incident Pack
post-publish / handoff pack05
發生事故時，Audit Trail 還要被整理成 Incident Pack。它回答三個問題：當下發生什麼、誰做了什麼、現在是否真的恢復。包含時間線、部署版本、健康檢查結果、回滾證據和目前狀態，讓接手的人不用重新猜測現場。

05 / FAIL-CLOSED

NO EVIDENCE · NO SUCCESS

不要用推測填補證據缺口。

寧可 Blocked，也不要回報一個假的成功。

AI 整理證據，但不能替人類發明證據。

post-publish / rejection is evidence06
這裡最重要的是 fail-closed。缺少部署事件，直接阻擋；事故沒有 resolved 事件，不回報成功；混入不同 change id，也直接拒絕。AI 可以幫忙整理證據，但不能用推測填補缺口。寧可輸出 Blocked，也不要產生看起來漂亮、實際無法追責的成功訊息。

07 / CLOSE THE LOOP

TRACE → RECOVER

發布之後，才是真正的考驗。

可追溯，才可復原。

需求→Context→執行→Verify→Deliver→Release→Recover
Audit Trail＋Incident Pack＋fail-closed＝責任鏈完成
ChatGPT × Codex：把每一次變更，留下下一次能接手的證據。
從需求、Context、執行、Verify、Deliver Pack，到 Release Gate，責任鏈不能在發布按鈕之後斷掉。Audit Trail 讓變更可追溯，Incident Pack 讓事故可交接，fail-closed 讓不完整證據不能冒充成功。發布不是終點；可追溯、可復原，才是這條鏈真正完成的地方。
